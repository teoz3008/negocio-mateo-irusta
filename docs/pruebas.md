# Pruebas del proyecto
- Prueba de productos
Verificar que se puedan consultar los productos registrados en la base de datos.
- Prueba de clientes
Comprobar que los clientes registrados se muestren correctamente.
- Prueba de pedidos
Verificar que los pedidos estén relacionados con sus clientes y detalles correspondientes.
- Prueba de métodos HTTP
Comprobar el funcionamiento de GET, POST, PUT, PATCH y DELETE.
- Prueba de PokéAPI
Verificar que la aplicación pueda mostrar información cuando se busca un Pokémon existente y un mensaje de error cuando no existe.
