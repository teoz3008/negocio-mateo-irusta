# Consulta a PokéAPI
- Descripción
PokéAPI es una API pública que permite obtener información sobre Pokémon.
- Objetivo
Consultar información de un Pokémon mediante una petición HTTP GET.
- que funciona?
1. El usuario ingresa el nombre de un Pokémon.
2. La aplicación realiza una petición a PokéAPI.
3. Si el Pokémon existe, se muestran sus datos.
4. Si no existe, se muestra un mensaje de error.
